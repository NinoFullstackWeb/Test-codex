# Odločitve prototipa

- Uporabniška zahteva določa brskalniški mobilni prototip; zato je izveden brez Expo ali zunanjih odvisnosti.
- Uporabljeni so slovenski zavihki in sivinska paleta brez ikon, fotografij, animacij ali okrasnih učinkov.
- Primeri idej in položaji oznak so izmišljeni predstavitveni podatki ter so v vmesniku označeni kot demo.
- Shranjene ideje, izbrano mesto in interesi se shranijo lokalno v brskalniku. Prijava, strežniška sinhronizacija in navigacija po resničnem zemljevidu niso del prototipa.
