# Ročni pregled prototipa

- [ ] Odpri stran na širini telefona in preveri vseh pet zavihkov.
- [ ] Poišči idejo po naslovu ali mestu; preveri prazno stanje.
- [ ] Uporabi filtre kategorije, brezplačno, okolje in trajanje.
- [ ] Odpri podrobnosti, shrani idejo in jo odstrani.
- [ ] Osveži stran; shranjena ideja naj ostane v zavihku Shranjeno.
- [ ] Izberi mesto, interes in oznako na demo zemljevidu.
- [ ] Preveri delovanje pri širini 320 px in na širšem zaslonu.
